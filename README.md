# Market Lens 🔍

A hands-on project for learning AI/ML engineering, starting from raw data analysis.

## What it does (and where it is going)

Market Lens analyzes financial price data and grows in capability as the project matures:

- **Phase 0: Data & analysis** *(done)*: pull real market data, compute returns and moving averages, and visualize trends with NumPy and pandas.
- **Phase 1: Machine learning**: engineer features and train models to predict price movement.
- **Phase 2: Deep learning & deployment**: build a neural/LLM-powered version and deploy it as a live app.
- **Phase 3: Security**: red-team the system and harden it against attacks.

## Tech stack

Python · NumPy · pandas · Matplotlib · yfinance

## Status

Only Phase 0 exists so far: a Jupyter notebook that pulls price data and computes returns and moving averages. The later phases are plans, not code, and the project is paused while I focus on detection engineering.
